# Retain Frontend

React + TypeScript + Vite frontend for Retain.

## Deployment

The Backend is deployed on Render.
https://retain-app-frontend-virid.vercel.app/

## Local development

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Deployment

- Deploy this repo on Vercel.
- Set `VITE_API_URL` to your Render backend URL, for example `https://retainapp-api.onrender.com/api`.
